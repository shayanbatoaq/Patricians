# Patricians

Patricians is a design and technology studio I co-founded. This repository contains the studio's website and demonstrates the engineering behind our client-facing presence, contact workflow, and digital product positioning.

## What I work on

At Patricians, I work across product strategy, full-stack development, and client delivery—from initial requirements and solution planning through design, implementation, deployment, and ongoing iteration. My responsibilities also include project scoping, proposals, client communication, digital strategy, and exploring practical AI-enabled product and workflow opportunities.

## Engineering highlights

- Built with **Next.js 16**, **React 19**, **TypeScript**, and **Tailwind CSS 4**.
- Motion and interaction work uses **Framer Motion**.
- Server-side integrations include **Notion** and **Resend**.
- Includes automated tests alongside linting and production-build checks.
- Structured as a modern Next.js application rather than a static marketing export.

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Notion API
- Resend

## Local development

Requires Node.js `>=20.9.0 <23`.

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm test
npm run build
```
